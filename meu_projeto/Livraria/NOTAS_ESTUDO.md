### 1- O que difere um Projeto de Software de um Script/Código Isolado?

Um Projeto de Software é mais completo e complexo, buscando resolver um problema ou atender às necessidades de um cliente. Ele precisa de planejamento, documentação, testes, manutenção e pode envolver um grupo de pessoas trabalhando juntas.

Um script ou código isolado é um pequeno programa simples, feito rapidamente, criado para executar uma tarefa específica e não precisa passar por todas as etapas de um Projeto de Software.

Sendo assim, um script ou código isolado é um programa simples para executar uma tarefa específica, enquanto um Projeto de Software é um programa mais complexo que requer planejamento e testes, a fim de executar uma tarefa específica ou atender às necessidades de um cliente.

### 2- Ciclo de Vida de um Projeto de Software

Levantamento de Requisitos - Os desenvolvedores buscam entender o que o cliente realmente precisa.

Desenvolvimento/Codificação - O projeto começa a ser "construído", e os códigos começam a ser desenvolvidos.

Testes/Qualidade - O sistema é testado para identificar falhas.

Entrega/Implantação - O software fica disponível para o cliente.

### 3- Por que definir um escopo fechado antes de iniciar a codificação?

Porque o escopo define exatamente o que será desenvolvido, para que a equipe saiba o que deve ser feito e quais são os objetivos do projeto, sem mudanças de rota no meio do caminho. Assim, o desenvolvimento fica mais organizado e aumentam as chances de entregar o software conforme o esperado pelo cliente.
