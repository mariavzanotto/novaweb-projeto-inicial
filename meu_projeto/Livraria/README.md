### Projeto NovaWeb Studio

## Livraria Bergaz

Repositório do Projeto 01 desenvolvido durante o curso de Desenvolvimento de Sistemas.

## Descrição do Projeto

A **Livraria Bergaz** é uma plataforma web voltada ao acesso e à compra de livros. O projeto tem como proposta oferecer uma interface simples, organizada e agradável para que os usuários possam conhecer livros disponíveis para compra e acessar **PDFs de obras que estão em domínio público**.

A plataforma busca facilitar o acesso aos livros por meio de uma navegação intuitiva e de uma organização clara das informações.

## Objetivo

Desenvolver uma plataforma web de livraria que possibilite:

* Apresentar livros disponíveis para compra;
* Disponibilizar PDFs de obras em domínio público;
* Facilitar a busca por livros;
* Organizar as informações das obras;
* Permitir a navegação entre as páginas;
* Oferecer uma interface simples e intuitiva.

## Requisitos do Sistema

### Requisitos Funcionais (RF)

* **RF01:** O sistema deve apresentar uma página inicial (Home) com informações sobre a plataforma.
* **RF02:** O sistema deve permitir a navegação entre as páginas por meio de um menu de navegação.
* **RF03:** O sistema deve disponibilizar uma biblioteca com livros em domínio público para acesso em PDF.
* **RF04:** O sistema deve apresentar livros disponíveis para compra.
* **RF05:** O sistema deve disponibilizar uma página de contato.
* **RF06:** O sistema deve permitir a busca por livros.
* **RF07:** O sistema deve apresentar informações relacionadas aos livros disponíveis.

### Requisitos Não Funcionais (RNF)

* **RNF01:** O site deve possuir uma interface simples, intuitiva e de fácil navegação.
* **RNF02:** O sistema deverá ser desenvolvido utilizando tecnologias web adequadas à implementação da plataforma.
* **RNF03:** O site deve possuir uma identidade visual padronizada.
* **RNF04:** O sistema deve apresentar organização adequada dos arquivos e diretórios.
* **RNF05:** O site deve possuir uma estrutura preparada para futuras expansões.

## Identidade Visual

A identidade visual da Livraria Bergaz foi desenvolvida buscando uma aparência moderna, organizada e agradável.

A proposta utiliza tons claros e lilás, seguindo o **Guia de Estilo Inicial** desenvolvido para o projeto.

Entre os elementos definidos estão:

* Paleta de cores;
* Tipografia;
* Logotipo;
* Ícones;
* Elementos de navegação;
* Organização visual das páginas.
